# راهنمای هوشمند موزه — آواتار هوش مصنوعی

پلتفرمی که بازدیدکننده با اسکن QR کنار هر اثر بازش می‌کند، سؤالش را می‌پرسد
(صوتی یا متنی) و یک آواتار سخنگو بر پایهٔ محتوای خودِ موزه پاسخ می‌دهد.

رندر چهره و لب‌سینک کاملاً روی گوشی بازدیدکننده اجرا می‌شود؛ بنابراین
هزینهٔ متغیر هر بازدید صفر است و تعداد بازدیدکنندهٔ هم‌زمان سقفی ندارد.

## اجرای محلی

خروجی ایستا است و هیچ فرآیند build ندارد:

```bash
python3 -m http.server 8000
```

- `http://localhost:8000/` صفحهٔ فرود و ابزار ساخت لینک هر اثر
- `http://localhost:8000/app/viewer.html?mock=1` صفحهٔ بازدیدکننده (دادهٔ نمایشی)
- `http://localhost:8000/app/studio.html` استودیوی کالیبراسیون آواتار

پارامترهای صفحهٔ بازدیدکننده:

| پارامتر | معنی |
|---|---|
| `bot` | شناسهٔ بات در ragbuilder |
| `obj` | شناسهٔ اثر — به‌عنوان context به RAG تزریق می‌شود |
| `t` | عنوان اثر برای نمایش |
| `av` | آواتار: `mehrbanoo` / `ostad` / `kimia` |
| `lang` | `fa` / `en` / `ar` |
| `mock=1` | اجرای بدون بک‌اند |

## ساختار

```
app/js/avatar.js         موتور لب‌سینک دوبعدی روی هر پرتره
app/js/audio-visemes.js  استخراج پارامتر دهان از سیگنال صوتی
app/js/sentences.js      شکستن جریانی پاسخ به جمله
app/js/rag-client.js     آداپتور ragbuilder با SSE / JSON / mock
app/js/tts.js            گفتارسازی سروری یا مرورگری با کش
app/js/stt.js            ورودی گفتار با تنزل تدریجی
app/js/config.js         پیکربندی مرکزی
app/studio.html          ساخت پروفایل آواتار از روی یک عکس
tools/make_qr.py         تولید انبوه QR از CSV آثار
```

## اتصال به بک‌اند

مقادیر بخش `rag` در `app/js/config.js` بر اساس ویجت فعلی حدس زده شده و هنوز
با API واقعی تطبیق داده نشده است. جزئیات و فهرست اقلامی که باید تأیید شود در
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) آمده.

برای پیکربندی هر موزه، پیش از بارگذاری اسکریپت:

```html
<script>
  window.MUSEUM_CONFIG = {
    rag: { botUUID: '...' },
    tts: { mode: 'server', endpoint: 'https://tts.example.com/speak' }
  };
</script>
```

## نکتهٔ مهم دربارهٔ صدا

پوشش صدای فارسی در مرورگرها ضعیف است؛ روی iOS عملاً وجود ندارد. برای
استقرار واقعی، TTS سمت سرور (پیشنهاد: Piper با صدای `fa_IR`) الزامی است، نه
اختیاری. دلیل فنی‌اش در سند معماری توضیح داده شده.
