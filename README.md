# راهبر خدمات قضایی دادنو

پیاده‌سازی اجرایی بستهٔ قرارداد: اسکیما، API، رندر سمت سرور، موتور مواعد،
خط لولهٔ بازیابی، هارنس ارزیابی و بررسی‌های خودکار قواعد مهندسی.

**استک:** Python 3.11 · FastAPI · PostgreSQL 16 + pgvector · Jinja2 (SSR، RTL)

---

## شروع سریع

```bash
make install            # virtualenv و وابستگی‌ها
docker compose up -d db # یا یک Postgres 16 با pgvector، pg_trgm، unaccent
make db-reset           # اجرای db/001 تا db/003
make demo               # seed + کاربران کارمند + کاتالوگ approved (فقط دمو)
make run                # http://localhost:8000
```

بدون `make demo`، هیچ خدمتی سرو نمی‌شود و صفحهٔ خانه خالی است. این باگ
نیست: تا تأیید کارشناس حقوقی، هیچ رکوردی به کاربر نهایی نمی‌رسد
(ENGINEERING_RULES.md §۲). `--approve-catalog` صراحتاً می‌گوید دارد تأیید
را جعل می‌کند و فقط برای محیط توسعه است.

```bash
make check     # قواعد مهندسی + lint + تست (همان چیزی که CI اجرا می‌کند)
make eval      # مجموعهٔ طلایی
make worker    # بازایندکس و یادآور
```

## سه تصمیمی که باید بدانید

### ۱. دروازهٔ pre-flight دو شرط دارد، نه یکی

`prompts/02_answer.md` می‌گوید اگر `score_top < 0.016` بود، مدل صدا زده
نشود. در عمل این آستانه به تنهایی **هرگز فعال نمی‌شود**: بازوی برداری
`hybrid_search` یک kNN بدون فیلتر است و همیشه ۱۰۰ ردیف برمی‌گرداند، پس
رتبهٔ ۱ همیشه `1/(60+1) = 0.01639` امتیاز می‌گیرد — چه پرسش «ابلاغیه آمده»
باشد چه «قیمت دلار چنده». هر دو دقیقاً یک امتیاز می‌گیرند.

`db/002_search.sql` دست‌نخورده مانده است. به جای آن، دروازه در
`retrieval.passes_gate` دو شرطی شد: آستانهٔ امتیاز **و** یک کف شباهت واقعی
(فاصلهٔ کسینوسی). با همین تغییر، «قیمت دلار چنده» درست امتناع می‌شود.

عدد فاصله به ارائه‌دهندهٔ امبدینگ گره خورده است. `make calibrate` آن را از
روی مجموعهٔ طلایی درمی‌آورد و **با هر تعویض provider باید دوباره اجرا شود**.

### ۲. ارائه‌دهنده‌های پیش‌فرض، مدل نیستند

`hashing` (امبدینگ) و `heuristic` (مدل زبانی) عمداً آفلاین‌اند تا کل خط
لوله، تست‌ها و CI بدون کلید API اجرا شود. کیفیت بازیابی با این‌ها پایین
است و **نباید** مبنای تصمیم محصولی گرفته شود. برای ارزیابی واقعی:

```bash
export DAADNO_EMBEDDING_PROVIDER=openai_compatible
export DAADNO_EMBEDDING_API_BASE=... DAADNO_EMBEDDING_API_KEY=...
export DAADNO_LLM_PROVIDER=anthropic DAADNO_LLM_API_KEY=...
make calibrate && make eval
```

طبق T-102، این تعویض هیچ کد فراخواننده‌ای را عوض نمی‌کند.

### ۳. کیفیت پاسخ الان سقف محتوایی دارد، نه فنی

از ۱۲ خدمت seed، ۱۱ تا فقط `TODO_CONTENT` دارند. چانک‌ساز عمداً محتوای
`TODO_CONTENT` را ایندکس نمی‌کند (چانک خالی، امتناع درست را به پاسخ غلط
تبدیل می‌کند)، پس این خدمات فقط یک چانک «خلاصه» دارند. Recall در اجرای
نمونه حدود ۲۵٪ است و با پر شدن محتوا بالا می‌رود، نه با تغییر کد.

این همان چیزی است که README بستهٔ قرارداد گفته بود: گلوگاه، تولید محتوای
دقیق است، نه کدزنی.

### استثناها صریح‌اند

چند فایل ناگزیر واژه‌های ممنوع را می‌نویسند تا آن‌ها را **رد** کنند.
به جای حدس زدن، نشانهٔ صریح لازم است تا هر استثنا در دیف دیده شود:

```python
# rules-ok(§1): فهرست سیاه است، نه ذخیره‌سازی
forbidden = {"password", "sana_password", ...}
```

و برای فایلی که کارش آزمودن خود قاعده است، یک خط در سربرگ:
`rules-ok-file(§1): ...`

### انحراف از T-005

تیکت Next.js خواسته بود؛ SSR اینجا با Jinja2 داخل همان سرویس FastAPI
پیاده شده است. معیارهای پذیرش برآورده می‌شوند — `view-source` محتوای فارسی
کامل دارد (نه فقط JS)، متادیتای SEO و JSON-LD نوع `HowTo` رندر می‌شوند،
`robots.txt` و `sitemap.xml` هست، و صفحه بدون جاوااسکریپت خوانا است
(تست: `tests/test_web.py`).

دلیل: نگه داشتن یک استک به جای دو، تا تیم بتواند فاز ۰ را بدون استخدام
فرانت‌اند ببندد. اگر می‌خواهید به Next.js بروید، قرارداد API دست‌نخورده
است و `web/` را می‌شود جدا کرد؛ ماژول‌های `catalog.py` و
`web/routes.build_json_ld` مرز تمیزی برای این کار دارند.

صفحات «پرونده‌های من» و پنل ادمین هنوز UI ندارند و فقط از API در دسترس‌اند.

## آنچه هنوز مالک انسانی می‌خواهد

- **اعداد مهلت.** هر ۸ قاعده `duration_value = NULL` است و دیتابیس جلوی
  approve شدنشان را می‌گیرد. تا آن زمان `POST /cases/{id}/eblagh` آرایهٔ
  `deadlines` خالی و `unavailable_rules` پر برمی‌گرداند — با ذکر دلیل.
- **جدول تعطیلات.** تا پر نشدن، `extend_if_ends_on_holiday` فقط جمعه‌ها را
  می‌بیند. پاسخ API فیلد `holiday_table_empty` دارد تا UI هشدار بدهد.
- **`TODO_CONTENT`ها و ۲۸ خدمت بعدی** (T-108).
- **۲۰۰ ردیف مجموعهٔ طلایی.** هارنس آماده است؛ `--enforce` را وقتی روشن
  کنید که مجموعه کامل شده باشد.
- **متن نهایی سلب مسئولیت** با تأیید تیم حقوقی؛ نسخهٔ فعلی در `guards.py`
  جایگزین‌پذیر است.

## نکات عملیاتی

- در `DAADNO_ENVIRONMENT=production`، اگر `PHONE_HMAC_KEY` یا `JWT_SECRET`
  مقدار پیش‌فرض باشند، اپ بالا نمی‌آید.
- تغییر `PHONE_HMAC_KEY` همهٔ کاربران موجود را از حسابشان جدا می‌کند
  (HMAC عوض می‌شود). چرخش کلید نیاز به مهاجرت دارد.
- رمزنگاری در سکون برای `user_case`، `eblagh_event`، `draft_document` (§۶)
  در لایهٔ استقرار انجام می‌شود (رمزنگاری دیسک/دیتابیس)؛ اسکیما فرض کرده
  این لایه هست.
- `answer_log` متن خام پرسش کاربر را نگه می‌دارد. سیاست نگهداری و حذف
  دوره‌ای آن باید پیش از پرودکشن تعیین شود.
