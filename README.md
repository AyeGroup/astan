# پژوهش — سکوی هوشمندی پژوهش شخصی

نمونه اولیه کارآمد از MVP توصیف‌شده در
*UX Product Specification — Personal Research Intelligence Platform v1.0*،
رابط فارسی و راست‌به‌چپ، با زبانی ساده.

> **همه‌چیز را نخوانید. آنچه مهم است را بدانید.**

## اجرا

بدون مرحله ساخت و بدون وابستگی — فقط HTML، CSS و ماژول‌های ES.

```bash
npx http-server -p 8000 .     # یا: python3 -m http.server 8000
# سپس http://localhost:8000
```

از صفحه فرود شروع کنید، با هر ایمیلی ثبت‌نام کنید و راه‌اندازی سه‌مرحله‌ای فید را می‌سازد.
همه وضعیت در `localStorage` می‌ماند؛ **تنظیمات ← بازنشانی** پاکش می‌کند.

## تصمیم‌های طراحی

**یک ستون، از بالا به پایین.** ناوبری در نوار بالاست و محتوا در یک ستون وسط.
داشبورد چندبخشی حذف شد؛ صفحه خانه را مثل یک خبرنامه از بالا به پایین می‌خوانید.

**یک فونت.** فقط وزیرمتن، با تفاوت وزن برای سلسله‌مراتب. فونت دوم صفحه را
سنگین‌تر می‌کرد، نه غنی‌تر.

**قرمز فقط تأکید است.** سطح بزرگ قرمز نداریم. قرمز روی چیزهایی می‌نشیند که
می‌شود رویشان کلیک کرد یا باید دیده شوند. زمینه سفید می‌ماند.

**هر مقاله می‌گوید چرا اینجاست.** زیر هر عنوان یک خط صورتی هست: «چرا برای شما؟»
لازم نیست کسی دکمه‌ای بزند تا دلیل را ببیند.

**در صفحه مقاله، هر بخش برچسب دارد.** «خلاصه در ۳ خط»، «نکته‌های مهم»،
«چرا این را به شما نشان دادیم»، «نسبت به چیزهایی که خوانده‌اید». همیشه
می‌دانید دارید چه می‌خوانید.

**نگارش فارسی.** متن‌ها با این قاعده‌ها ویرایش شده‌اند:

- «را» بلافاصله بعد از مفعول می‌آید، نه بعد از یک جمله‌واره بلند.
  («سایت‌هایی که برایتان مهم است را اضافه کنید» ← «موضوع‌های مورد علاقه‌تان را انتخاب کنید»)
- هر فعل مفعول خودش را دارد. زنجیره فعل بی‌مفعول نداریم.
- استعاره ترجمه‌ای نداریم. «جلو می‌آوریم» جای خودش را به «نشان می‌دهیم» داده.
- جمله تلگرافی نداریم. معلوم است چه کسی چه کاری می‌کند.
  («اشتباه بود؟ بگویید تا درست شود» ← «اگر انتخاب خوبی نبود، با یک کلیک به ما بگویید»)
- اسم مشخص به‌کار می‌رود: «مقاله»، نه «مطلب» و «محتوا».
- ترکیب اضافی مبهم نداریم. «خلاصه امروز شما» ← «۳ خبر مهمی که امروز برایتان پیدا کردیم».

**اعداد فارسی، تاریخ شمسی.** متن لاتین — نام نشریه، نویسنده، دامنه — در
جزیره‌ای با جهت و فونت خودش می‌نشیند.

## ساختار

```
index.html               پوسته: dir=rtl، فونت‌ها، توکن‌ها، نقطه ورود
assets/css/tokens.css    توکن‌های طراحی — رنگ، تایپ، فاصله، حرکت (روشن و تاریک)
assets/css/app.css       اجزا و چیدمان (logical properties برای RTL)
assets/js/app.js         پوسته، ناوبری، پالت جست‌وجو، اقدامات سراسری
assets/js/router.js      مسیریاب هش
assets/js/store.js       وضعیت، ماندگاری، سیگنال‌های شخصی‌سازی
assets/js/data.js        پیکره نمونه (مقاله، منبع، موضوع، خط زمانی)
assets/js/ui.js          آیکون، واگذاری رویداد، مودال، توست، اعداد و تاریخ فارسی
assets/js/views/         یک ماژول برای هر ناحیه از رابط
assets/js/views/translate.js  صفحه مترجم: انتخاب منبع، ترجمه، خلاصه، نکته‌ها
```

## مرزهای این نمونه

پشتیبانی سمت سرور وجود ندارد: هیچ خزش، استخراج، ترجمه یا فراخوانی مدلی رخ نمی‌دهد.
افزودن مقاله و سایت، مسیر تعاملی واقعی را روی داده تولیدشده اجرا می‌کند و همین را
روی صفحه می‌گوید، به‌جای اینکه متن مقاله از خودش بسازد. متن فارسی مقاله‌های نمونه
نوشته شده است، نه ترجمه ماشینی؛ متن اصلی هر مقاله هم زیر کلید «اصلی» در دسترس است.
