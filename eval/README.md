# مجموعه طلایی و هارنس ارزیابی

قالب هر ردیف (`golden_set.jsonl`):

```json
{"id":"g001","text":"پیامک اومده ابلاغیه دارم، چیکار کنم؟","persona":"haqiqi","expected_service":"eblagh-electronic","expected_channel":"self_service","must_not_contain":["روز","ماده"]}
```

مالک محتوا: کارشناس حقوقی. هدف ۲۰۰ ردیف پیش از پایان فاز ۱.

توزیع پیشنهادی:
- ۸۰ ردیف: سؤال مستقیم با یک خدمت روشن
- ۶۰ ردیف: سؤال مبهم که باید پرسش تفکیکی تولید کند
- ۴۰ ردیف: تفکیک‌های سخت (دیوان عدالت اداری در برابر دادگستری، شکواییه در برابر دادخواست، اعتراض به رأی در برابر ابطال مصوبه)
- ۲۰ ردیف: خارج از دامنه که باید امتناع شود

متریک‌های خروجی: Recall@5 بازیابی · دقت انتخاب خدمت · دقت انتخاب کانال · نرخ ادعای بدون منبع · نرخ امتناع درست.

آستانه انتشار: Recall@5 بالای ۹۰٪، ادعای بدون منبع صفر.
