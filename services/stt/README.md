# سرویس تشخیص گفتار فارسی — راهنمای هوشمند موزه

سرویس STT سلف‌هاست بر پایهٔ `faster-whisper`، با VAD و فیلتر توهم که برای
محیط پرسروصدای موزه تنظیم شده.

## مسئلهٔ اصلی: توهم، نه دقت

بدترین شکست Whisper در موزه بد شنیدن یک کلمه نیست؛ **ساختن جمله از دل سکوت**
است. مدل روی دادهٔ زیرنویس آموزش دیده، پس وقتی چیزی برای رونویسی نیست،
متن تبلیغاتی زیرنویس تولید می‌کند: «زیرنویس از کانال...»، «لطفا کانال را
دنبال کنید»، `Thanks for watching`.

بازدیدکننده‌ای که تصادفی به دکمهٔ میکروفون بخورد، آواتار را می‌بیند که با
جدیت به سؤالی که هیچ‌کس نپرسیده جواب می‌دهد — و این بدتر از هیچ‌جواب است.

دو خط دفاعی مستقل:

**عددی** — `no_speech_prob` و `avg_logprob` خودِ Whisper، به‌علاوهٔ نسبت
کاراکتر بر ثانیه. توهم معمولاً یک جملهٔ روان و بلند روی کلیپی بسیار کوتاه است؛
گفتار فارسی حدود ۱۲ تا ۱۸ کاراکتر بر ثانیه است و خیلی بالاتر از آن یعنی متنی
بدون صوتِ توجیه‌کننده ظاهر شده.

**واژگانی** — فهرست سیاه همان متن‌هایی که مدل واقعاً تولید می‌کند، و آشکارساز
تکرار برای شکست کلاسیک دیگر: افتادن رمزگشا در حلقه و تکرار یک عبارت.

هر دو لازم‌اند: بررسی عددی یک توهم بااعتماد روی همهمهٔ جمعیت را از دست می‌دهد،
و فهرست سیاه یک ساختهٔ تازه را.

## سه تصمیم دیگر که برای موزه مهم‌اند

**زبان اجباری، نه تشخیص خودکار.** یک جملهٔ کوتاه در سالن پرسروصدا آن‌قدر
اشتباه تشخیص داده می‌شود که ارزش ریسک ندارد. صفحه از قبل زبانش را می‌داند.

**`condition_on_previous_text=False`.** هر جمله مستقل است و حمل context بین
جمله‌ها عامل اصلی حلقه‌های تکرار Whisper است.

**رد کردن به‌جای صف.** Whisper CPU-bound است؛ همزمانی نامحدود یک دقیقهٔ شلوغ
را به صفی تبدیل می‌کند که کسی از آن بیرون نمی‌آید. بازدیدکننده‌ای که ۲۰ ثانیه
پشت رونویسی دیگران منتظر بماند، رفته است. سرویس `429` می‌دهد.

## اجرا

```bash
pip install -r requirements.txt

# ۱. دریافت مدل — جایی که huggingface.co در دسترس است
./scripts/fetch_model.sh medium ./models

# ۲. اجرا
STT_BACKEND=whisper STT_MODEL=medium uvicorn app.main:app --port 8081
```

یا `docker compose up -d`.

بدون مدل، سرویس با بک‌اند `dev` بالا می‌آید: رمزگشایی صوت و پس‌پردازش واقعی
اجرا می‌شود و یک متن ثابت برمی‌گردد. فقط برای توسعه و CI —
`/health` آن را با `production_ready: false` علامت می‌زند.

## API

| مسیر | کار |
|---|---|
| `POST /transcribe` | multipart با فیلد `audio` (و `lang` اختیاری) → `{"text": "..."}` |
| `GET /health` | آمادگی، بک‌اند، مدل، ظرفیت آزاد |

نمونه:

```json
{
  "text": "قدمت این اثر چقدر است",
  "language": "fa",
  "duration": 1.632,
  "rejected": false,
  "reason": null,
  "rtf": 0.41,
  "elapsed_ms": 669
}
```

`rtf` نسبت زمان پردازش به طول صوت؛ زیر ۱ یعنی سریع‌تر از بی‌درنگ.

**نکتهٔ مهم قراردادی:** جمله‌ای که فیلترها رد می‌کنند با `200` و متن **خالی**
برمی‌گردد، نه با خطا. کلاینت خالی را «چیزی گفته نشد» تفسیر می‌کند و ساکت
می‌ماند — دقیقاً رفتار درست وقتی کسی تصادفی به دکمه می‌خورد.

## سازگاری با مرورگرها

`MediaRecorder` در کروم و فایرفاکس `WebM/Opus` می‌دهد و در سافاری `MP4/AAC`.
رمزگشایی با PyAV انجام می‌شود که کتابخانه‌های FFmpeg خودش را همراه دارد، پس
نه `ffmpeg` سیستمی لازم است نه زیرفرایندی برای مدیریت. هر دو قالب تست شده‌اند.

## انتخاب مدل برای فارسی

| مدل | سرعت روی CPU | مناسب |
|---|---|---|
| `small` | سریع‌ترین | وقتی تأخیر از دقت مهم‌تر است |
| `medium` | ۲ تا ۴ برابر بی‌درنگ | **پیش‌فرض منطقی موزه** |
| `large-v3` | کند روی CPU | دقیق‌ترین؛ GPU می‌خواهد |

## تست

```bash
python3 -m pytest tests/ -q
```

سه لایه: رمزگشایی صوت (با فایل‌های واقعی WebM/Opus و MP4/AAC که خود تست
می‌سازد)، فیلتر توهم، و قرارداد HTTP.

## پیکربندی

| متغیر | پیش‌فرض | کار |
|---|---|---|
| `STT_BACKEND` | `auto` | `whisper` \| `dev` \| `auto` |
| `STT_MODEL` | `medium` | اندازهٔ مدل |
| `STT_MODEL_DIR` | `./models` | محل مدل دانلودشده |
| `STT_DEVICE` | `cpu` | `cpu` \| `cuda` |
| `STT_COMPUTE_TYPE` | `int8` | کوانتیزاسیون |
| `STT_LANGUAGE` | `fa` | زبان اجباری |
| `STT_MAX_CONCURRENT` | `2` | سقف رونویسی هم‌زمان |
| `STT_MAX_SECONDS` | `30` | سقف طول کلیپ |
| `STT_PROMPT` | واژگان موزه | بایاس رمزگشایی به سمت اصطلاحات تخصصی |

## اتصال به فرانت‌اند

```html
<script>
  window.MUSEUM_CONFIG = {
    stt: { mode: 'server', endpoint: 'https://stt.example.com/transcribe' }
  };
</script>
```

`app/js/stt.js` اگر endpoint سروری نداشته باشد به `webkitSpeechRecognition`
مرورگر برمی‌گردد و اگر آن هم نبود، دکمهٔ میکروفون را پنهان می‌کند.
